# SEO

- **Language:** `<html lang="es">`, `og:locale es_CO`, Spanish copy throughout.
- **Per-route HTML:** `scripts/seo-routes.mjs` writes `dist/<route>/index.html` for `/`, `/seguridad`,
  `/integraciones` and `/contacto`, each with its own `<title>`, description, canonical, `og:url`, `og:title` and
  `og:description`, so crawlers and link unfurlers see correct metadata without running JavaScript.
  `dist/404.html` is `noindex`.
- **Client meta:** `src/app/meta.ts` keeps title, description and canonical in sync during client navigation.
- **Sitemap / robots:** generated into `dist/` (origin from `VITE_SITE_ORIGIN`); static copies are in `public/` for
  dev.
- **Structured data:** `SoftwareApplication` JSON-LD in `index.html` with name, category, description and publisher
  (TIGLOBAL). **No** `aggregateRating`, reviews, offers or user counts. We have none, and fabricating them is
  forbidden.
- **Social card:** `public/og-es.jpg` (1200×630), generated by `npm run og` from the official mark PNG, the Spanish
  headline and the candidate-journey motif. It contains no candidate data.
- **Semantics:** one `h1` (hero), an `h2` per section, `h3` inside; landmarks `header`, `nav` (primary, page journey,
  mobile menu), `main#contenido`, `footer`; a skip link.
- **Content:** no thin pages. Each subpage has substantive content (`/seguridad`, `/integraciones`, `/contacto`).
