# Integration status

Categories used on the website (directive §107):
- **BUILT-IN** — works inside RECRUIT4US with no outside service.
- **AVAILABLE WHEN CONFIGURED** — adapter exists in code; activates only when the listed server env vars (or in-app settings) are present. Not active in the current workspace (`docs/INTEGRATIONS.md:3`: "None of them are set in this preview").
- **NOT CURRENTLY CONNECTED** — no working adapter; do not show as an integration.

No third-party logos should be shown (directive §107-108). "Configured" in Connectors means env present, not that a live round-trip succeeded (`docs/DEPLOY.md` "After the first boot").
