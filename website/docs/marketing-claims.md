Every public claim on the RECRUIT4US website must map to a row here (directive §126). Statuses follow `feature-verification.md`. Safe wording is Spanish (LatAm, professional). Sources are app-repo paths.

Global rules for copy:
1. **Human decision.** RECRUIT4US produces evidence, criteria and ranks in specific places; people decide (`README.md:7`, directive §105).
2. **No AI.** The product contains no ML model. Never call the CV screen, expertise count, Boolean search, complexity estimate or scoreboard "IA" (`docs/IMPLEMENTATION_STATUS.md:13-15`, directive §106).
3. **Conditional integrations** carry "al configurarla / cuando está configurada" (directive §46, §49, §107).
4. **Numbers**: only numbers in this file. Do not invent metrics, customers, logos or testimonials (OWNER PROVIDED).
5. **Candidate-facing email** (invitations, codes, offers) reaches real inboxes only when SMTP is configured; don't imply otherwise.
